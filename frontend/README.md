# BeyondChats Web Scraper & Articles Dashboard

## 📌 Project Overview
This project scrapes AI chatbot blog articles from BeyondChats, stores them in a MySQL database, and displays them in a React-based analytics dashboard UI.

## 🚀 Features Implemented (Phase 1)
- Web scraping using **Puppeteer + Cheerio**
- Extracts blog article links from last page
- Scrapes article **title and main content**
- Stores data in **MySQL database**
- Backend API built with **Node.js (Express)**
- Dashboard UI built with **React + Custom CSS**
- Supports **Search, Stats, Table View, Reload**

## 🧠 Tech Stack
- **Frontend:** React.js, CSS
- **Backend:** Node.js, Express.js
- **Database:** MySQL (beyond_db)
- **Scraping:** Puppeteer, Cheerio
- **API Client:** Axios
- **Search API:** SerpAPI (for future phases)
